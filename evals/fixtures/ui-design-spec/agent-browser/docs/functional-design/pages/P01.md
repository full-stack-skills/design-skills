# P01 应用首页

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-01 FR-07

## 职责与入口

让用户打开应用、继续工作或发起新任务，不混入职位详情。

- 所属：个人/工作空间；导航归属：首页。
- 进入：启动、新标签首页、左侧首页。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

顶部问候与工作空间；中央统一输入和常用应用；下方最近工作、待确认任务；右侧 Agent 默认收起

| 稳定视图 | 职责 |
|---|---|
| P01-01 | 默认首页 |
| P01-02 | 最近工作 |

## 信息与输入

应用图标/名称/可用性；最近对象/来源/时间；任务状态/待处理原因

校验：输入框可选“搜索”或“交给 Agent”；空输入不能启动任务

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P01-S01**：首次使用无应用：展示内置示例与设置入口。
- **P01-E01**：最近记录来源已删除：保留记录说明并允许移除。
- **P01-R01**：应用/任务入口已打开，不替用户提交业务动作。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“已安装且权限有效”，执行“打开应用”，应观察到“按 app_id 打开或定位现有标签”，进入 P04-01；取消不产生新的写入。
4. 给定“目标非空且模型可用”，执行“交给 Agent”，应观察到“携带选定范围进入对话”，进入 A01-01；取消不产生新的写入。
5. 给定“任务仍有效”，执行“处理待办”，应观察到“定位任务详情”，进入 P11-01；取消不产生新的写入。
6. 人为制造“最近记录来源已删除：保留记录说明并允许移除”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“应用/任务入口已打开，不替用户提交业务动作”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
