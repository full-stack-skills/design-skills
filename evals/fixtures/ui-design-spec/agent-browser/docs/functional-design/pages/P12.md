# P12 成果与证据

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-07 FR-10

## 职责与入口

让用户查看、核对、导出或保存真实任务输出。

- 所属：工作空间/任务成果；导航归属：工作台 / 成果。
- 进入：任务结果、工作台成果。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

成果列表与类型过滤；详情预览；来源/时间/账号；保存与导出

| 稳定视图 | 职责 |
|---|---|
| P12-01 | 成果列表 |
| P12-02 | 成果详情 |

## 信息与输入

字段值；来源URL；快照时间；证据引用；验证状态

校验：推断与原文区分；过期来源标记；导出脱敏范围明确

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 操作合同

每次操作记录 source_surface、return_surface、对象版本及选中上下文。以下来源为默认父视图；若从其他子视图触发，以实际来源替代。取消和可恢复失败都留在实际来源，保留输入；涉及已执行的写入则显示回执，不能承诺取消即撤销。

| 操作面 | 来源 | 操作 | 前置条件 | 效果与成功去向 | 取消/失败 |

## 状态与结果

- **P12-S01**：任务未产生成果：回到任务查看原因。
- **P12-E01**：证据已过期/已删除：不能展示为可验证。
- **P12-R01**：导出或保存记录带来源，不提升为事实保证。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“选定成果且范围允许”，执行“保存到知识库”，应观察到“选择目录并保留来源”，进入 P13-01；取消不产生新的写入。
4. 给定“来源可访问”，执行“回看来源”，应观察到“打开原页面，不自动重放动作”，进入 P05-01；取消不产生新的写入。
5. 给定“选择格式与文件范围”，执行“导出成果”，应观察到“保存本地文件并反馈”，进入 P08-01；取消不产生新的写入。
6. 人为制造“证据已过期/已删除：不能展示为可验证”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“导出或保存记录带来源，不提升为事实保证”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
