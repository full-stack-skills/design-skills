# P03 应用中心

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-03 FR-04 FR-11

## 职责与入口

管理内置应用入口与可用状态，首期不建设任意插件市场。

- 所属：工作空间/应用；导航归属：工作台 / 应用中心。
- 进入：工作台应用区、首页管理应用。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 信息与输入

app_id；名称；版本；来源；所需能力；离线支持

校验：只展示经过校验的一方应用；新增权限不得默认授予

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 操作合同

每次操作记录 source_surface、return_surface、对象版本及选中上下文。以下来源为默认父视图；若从其他子视图触发，以实际来源替代。取消和可恢复失败都留在实际来源，保留输入；涉及已执行的写入则显示回执，不能承诺取消即撤销。

| 操作面 | 来源 | 操作 | 前置条件 | 效果与成功去向 | 取消/失败 |
|---|---|---|---|---|---|
| P03-A01 | P03-01 | 查看应用 | 应用清单有效 | 查看功能、权限和版本 → P04-01 | 取消回实际来源；校验失败原位指出原因；结果未知进入核对 |
| P03-A02 | P03-01 | 添加应用 | 一方包有效且未启用 | 展示本地能力授权 → G05-01 | 取消回实际来源；校验失败原位指出原因；结果未知进入核对 |
| P03-A03 | P03-01 | 停用应用 | 没有不可中断的关联操作 | 显示影响与保留数据策略 → G03-01 | 取消回实际来源；校验失败原位指出原因；结果未知进入核对 |

## 状态与结果

- **P03-S01**：无可添加应用：解释一方应用范围，不展示虚假商城。
- **P03-E01**：包校验失败：保持旧安装版本并展示原因。
- **P03-R01**：启用/停用后更新入口，业务数据不自动删除。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“应用清单有效”，执行“查看应用”，应观察到“查看功能、权限和版本”，进入 P04-01；取消不产生新的写入。
4. 给定“一方包有效且未启用”，执行“添加应用”，应观察到“展示本地能力授权”，进入 G05-01；取消不产生新的写入。
5. 给定“没有不可中断的关联操作”，执行“停用应用”，应观察到“显示影响与保留数据策略”，进入 G03-01；取消不产生新的写入。
6. 人为制造“包校验失败：保持旧安装版本并展示原因”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“启用/停用后更新入口，业务数据不自动删除”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
