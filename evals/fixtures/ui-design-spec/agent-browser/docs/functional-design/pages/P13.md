# P13 知识库

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-10

## 职责与入口

管理用户保存的文件、网页摘录和结构化成果。

- 所属：工作空间/资料；导航归属：知识库。
- 进入：左侧知识库。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

目录树；类型/关键词过滤；资料列表；导入入口；索引状态

## 信息与输入

标题；类型；来源；更新时间；索引状态；所属目录

校验：允许文件格式/大小；重复内容提示；导入不默认发送云模型

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P13-S01**：无资料：提供导入与保存网页入口。
- **P13-E01**：解析/索引失败：保留源文件并允许重试或移除。
- **P13-R01**：资料可查看，索引完成才标可检索。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“用户选择本地文件”，执行“导入资料”，应观察到“校验格式并建立资料记录”，进入 P14-01；取消不产生新的写入。
4. 给定“有访问权”，执行“查看资料”，应观察到“打开内容与来源”，进入 P14-01；取消不产生新的写入。
5. 给定“选择条目与范围”，执行“删除资料”，应观察到“说明索引/对象删除影响”，进入 G03-01；取消不产生新的写入。
6. 人为制造“解析/索引失败：保留源文件并允许重试或移除”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“资料可查看，索引完成才标可检索”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
