# P09 网站账号与会话

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-05 FR-08

## 职责与入口

隔离不同站点账号，管理登录状态和数据清除。

- 所属：工作空间/Profile；导航归属：设置 / 网站账号。
- 进入：设置网站账号、地址栏profile菜单。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

profile列表；站点身份摘要；活跃标签/任务；清除与登录入口

| 稳定视图 | 职责 |
|---|---|
| P09-01 | 账号列表 |

## 信息与输入

profile名称；站点；登录状态；最近验证；关联任务

校验：账号名称不等于已验证身份；禁止导入Chrome会话作为默认方案

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P09-S01**：尚无账号：创建空profile并登录。
- **P09-E01**：隔离验证失败或会话失效：禁止自动写入。
- **P09-R01**：账号状态刷新，旧批准失效。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“选定profile及站点”，执行“打开网站登录”，应观察到“打开可见网页登录”，进入 G04-01；取消不产生新的写入。
4. 给定“无未决写入或明确接管”，执行“切换账号”，应观察到“重新绑定并重观察”，进入 P05-01；取消不产生新的写入。
5. 给定“列出受影响任务与标签”，执行“清除站点数据”，应观察到“确认注销/存储影响”，进入 G03-01；取消不产生新的写入。
6. 人为制造“隔离验证失败或会话失效：禁止自动写入”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“账号状态刷新，旧批准失效”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
