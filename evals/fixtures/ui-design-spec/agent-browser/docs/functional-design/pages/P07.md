# P07 浏览历史

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-02

## 职责与入口

按时间检索和重新打开浏览记录，并明确清除范围。

- 所属：工作空间/Profile；导航归属：历史。
- 进入：左侧历史。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

日期分组与搜索；URL/标题列表；清除历史入口

| 稳定视图 | 职责 |
|---|---|
| P07-01 | 历史列表 |

## 信息与输入

访问时间；标题；域名；profile；记录数

校验：清除仅历史，不隐含注销账号、清Cookie或删除成果

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 操作合同

每次操作记录 source_surface、return_surface、对象版本及选中上下文。以下来源为默认父视图；若从其他子视图触发，以实际来源替代。取消和可恢复失败都留在实际来源，保留输入；涉及已执行的写入则显示回执，不能承诺取消即撤销。

| 操作面 | 来源 | 操作 | 前置条件 | 效果与成功去向 | 取消/失败 |
|---|---|---|---|---|---|
| P07-A01 | P07-01 | 重新打开 | 记录URL有效 | 在选定profile打开 → P05-01 | 取消回实际来源；校验失败原位指出原因；结果未知进入核对 |
| P07-A02 | P07-01 | 清除历史 | 选择时间范围 | 展示影响范围再确认 → G03-01 | 取消回实际来源；校验失败原位指出原因；结果未知进入核对 |

## 状态与结果

- **P07-S01**：没有匹配记录：可清空过滤。
- **P07-E01**：历史库不可读：停止清除并提示恢复。
- **P07-R01**：历史清除后不再可检索，书签和成果保留。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“记录URL有效”，执行“重新打开”，应观察到“在选定profile打开”，进入 P05-01；取消不产生新的写入。
4. 给定“选择时间范围”，执行“清除历史”，应观察到“展示影响范围再确认”，进入 G03-01；取消不产生新的写入。
5. 人为制造“历史库不可读：停止清除并提示恢复”，页面给出可操作恢复入口，不显示成功。
6. 实际结果符合“历史清除后不再可检索，书签和成果保留”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
