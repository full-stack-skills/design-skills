# J02 已保存职位与对比

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-09 FR-10

## 职责与入口

对比用户选中的职位并保留来源，不展示无依据匹配分数。

- 所属：示例应用/收藏；导航归属：招聘应用 / 已保存。
- 进入：职位收藏、应用已保存。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

收藏列表与选择框；对比表；移除与查看原文

## 信息与输入

公司；技术栈；年限；远程范围；薪资；更新时间；来源

校验：至少2条才对比；缺失字段显示未提供；去重按来源与ID

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **J02-S01**：没有收藏或不足2条：提供返回搜索入口。
- **J02-E01**：原职位下架：仍可看保存快照并标过期。
- **J02-R01**：对比结果只来自选择记录。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“至少选择2条可读职位”，执行“开始对比”，应观察到“进入字段对比”，进入 J02-02；取消不产生新的写入。
4. 给定“记录有来源”，执行“查看职位”，应观察到“回到对应职位或网页”，进入 J01-01；取消不产生新的写入。
5. 给定“确认选中范围”，执行“移除收藏”，应观察到“只删收藏，不删网站职位”，进入 G03-01；取消不产生新的写入。
6. 人为制造“原职位下架：仍可看保存快照并标过期”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“对比结果只来自选择记录”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
