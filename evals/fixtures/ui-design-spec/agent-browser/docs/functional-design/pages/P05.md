# P05 网页浏览

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-02 FR-05 FR-06

## 职责与入口

正常访问外部网站，保留可信地址和用户接管能力。

- 所属：网页/Profile；导航归属：浏览器标签。
- 进入：地址栏、书签、链接、新标签。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

宿主标签/地址/书签；中央独立网页；来源与加载状态；可选 Agent 面板

## 信息与输入

真实 URL/安全状态；页面标题；profile；加载/前进后退；页面错误

校验：只允许受支持协议；不得将外部导航继承为内置应用权限

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P05-S01**：加载/挂起：保留地址与取消入口，不能显示旧页面为新页面。
- **P05-E01**：证书/网络/崩溃错误：明确区分并提供返回或重试，禁止自动跳过证书。
- **P05-R01**：导航完成有真实 URL 和标题；不等于业务成功。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“URL通过协议校验”，执行“访问地址”，应观察到“创建导航记录并加载当前标签”，进入 P05-01；取消不产生新的写入。
4. 给定“用户选定当前页范围”，执行“交给 Agent”，应观察到“携带页面引用进入对话”，进入 A01-01；取消不产生新的写入。
5. 给定“站点需要认证”，执行“登录接管”，应观察到“突出可见网页并暂停依赖任务”，进入 G04-01；取消不产生新的写入。
6. 给定“当前地址有效”，执行“保存书签”，应观察到“选择文件夹并写书签”，进入 P06-01；取消不产生新的写入。
7. 人为制造“证书/网络/崩溃错误：明确区分并提供返回或重试，禁止自动跳过证书”，页面给出可操作恢复入口，不显示成功。
8. 实际结果符合“导航完成有真实 URL 和标题；不等于业务成功”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
