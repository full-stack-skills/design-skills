# P20 产品配置

设计 Draft · 实现未验收 · 范围 V1.1 · 对应 FR-11

## 职责与入口

用一套引擎配置多个产品，不复制浏览器业务代码。

- 所属：产品管理员；导航归属：设置 / 产品配置。
- 进入：有管理权限的设置入口。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

品牌/首页/应用/策略四区；预览；差异与发布

## 信息与输入

品牌名称；图标；启动应用；导航可见性；策略默认

校验：不能扩大用户已授予能力；保留全局恢复和设置入口

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P20-S01**：没有定制：使用标准Agent Browser。
- **P20-E01**：清单冲突：定位字段，不应用部分配置。
- **P20-R01**：版本化配置原子生效，可回到前一有效版本。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“清单合法”，执行“预览配置”，应观察到“仅预览首页和菜单”，进入 P01-01；取消不产生新的写入。
4. 给定“校验应用可用和权限交集”，执行“应用配置”，应观察到“确认影响”，进入 G03-01；取消不产生新的写入。
5. 人为制造“清单冲突：定位字段，不应用部分配置”，页面给出可操作恢复入口，不显示成功。
6. 实际结果符合“版本化配置原子生效，可回到前一有效版本”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
