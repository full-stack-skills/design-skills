# A01 Agent工作台

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-06 FR-07 FR-08 FR-10

## 职责与入口

以Codex为内嵌载体呈现对话、页面理解、任务和记忆，和网页并存。

- 所属：任务/选定上下文；导航归属：全局Agent侧栏。
- 进入：顶部Agent按钮、业务交给Agent。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

面板头部/连接状态；四页签；上下文chips；消息与工具事件；固定输入区；运行控制

| 稳定视图 | 职责 |
|---|---|
| A01-01 | 对话 |
| A01-02 | 页面理解 |
| A01-03 | 任务 |
| A01-04 | 记忆 |

## 信息与输入

输入目标；当前页/选中页/文件范围；模型；步骤；确认；证据

校验：输入法组合期间不发送；未连接只保留草稿；页面内容不能授权扩大范围

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **A01-S01**：空闲/运行/等待确认/接管/断连各显示真实状态。
- **A01-E01**：服务崩溃：输入保留，运行转待核对，不伪造完成。
- **A01-R01**：回复、工具执行和业务验证分层展示。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“连接就绪且目标非空”，执行“发送目标”，应观察到“创建任务与Codex turn并显示运行”，进入 A01-01；取消不产生新的写入。
4. 给定“用户主动选择”，执行“选择上下文”，应观察到“修改本次输入范围”，进入 G05-01；取消不产生新的写入。
5. 给定“有真实task_id”，执行“查看完整任务”，应观察到“打开详情”，进入 P11-01；取消不产生新的写入。
6. 给定“工作空间确定”，执行“管理记忆”，应观察到“查看可编辑记忆”，进入 P15-01；取消不产生新的写入。
7. 给定“运行时未就绪”，执行“连接智能体”，应观察到“进入连接配置”，进入 P17-01；取消不产生新的写入。
8. 人为制造“服务崩溃：输入保留，运行转待核对，不伪造完成”，页面给出可操作恢复入口，不显示成功。
9. 实际结果符合“回复、工具执行和业务验证分层展示”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
