设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-07 NFR-01

## 职责与入口

配置Codex载体、可用模型和认证，明确本地载体不等于本地模型。

- 所属：用户/智能体运行时；导航归属：设置 / 智能体。
- 进入：设置智能体、模型不可用提示。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 信息与输入

Codex版本；连接；认证状态；模型可用性；预算限制

## 状态与结果

- **P17-S01**：未配置：对话可写草稿但不能伪装执行。
- **P17-E01**：协议不兼容/认证失效/额度不足：区别原因。
- **P17-R01**：就绪必须有真实握手和可用能力证据。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“兼容版本与配置有效”，执行“连接运行时”，应观察到“握手并读取实际能力”，进入 P17-01；取消不产生新的写入。
4. 给定“用户主动发起”，执行“完成认证”，应观察到“进入所支持认证流程”，进入 G04-01；取消不产生新的写入。
5. 给定“连接已就绪”，执行“返回对话”，应观察到“允许发起任务”，进入 A01-01；取消不产生新的写入。
6. 人为制造“协议不兼容/认证失效/额度不足：区别原因”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“就绪必须有真实握手和可用能力证据”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
