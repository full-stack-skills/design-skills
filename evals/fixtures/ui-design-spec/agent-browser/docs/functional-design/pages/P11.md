# P11 任务详情

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-07 FR-08 FR-12

## 职责与入口

观察执行过程、接管和恢复，展示结果证据而非只有聊天。

- 所属：任务/执行；导航归属：任务 / 详情。
- 进入：任务行、Agent“查看任务”。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 信息与输入

task_id；thread/turn映射；步骤；开始结束；工具回执；未决动作

校验：暂停、取消、重试语义分别显示；重试前先核对未知提交

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P11-S01**：等待模型/工具/确认/接管时显示不同原因。
- **P11-E01**：结果未知：禁止重发并提供核对对象和人工处理。
- **P11-R01**：仅后置条件成立才显示成功。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“运行且可在安全点停止”，执行“暂停任务”，应观察到“停止后续动作并保留未决记录”，进入 P11-01；取消不产生新的写入。
4. 给定“显示可能已生效动作”，执行“取消任务”，应观察到“确认取消后续步骤”，进入 G03-01；取消不产生新的写入。
5. 给定“有证据引用”，执行“查看结果”，应观察到“打开结构化成果”，进入 P12-01；取消不产生新的写入。
6. 给定“登录/接管已完成”，执行“重新观察”，应观察到“重新生成页面版本”，进入 P11-01；取消不产生新的写入。
7. 人为制造“结果未知：禁止重发并提供核对对象和人工处理”，页面给出可操作恢复入口，不显示成功。
8. 实际结果符合“仅后置条件成立才显示成功”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
