## 信息与输入

## 状态与结果

- **J01-S01**：空结果：保留条件、显示清除筛选。
- **J01-E01**：来源刷新失败：标旧数据时间，不显示最新。
- **J01-R01**：搜索/收藏有真实数据结果，不虚构投递成功。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“条件合法”，执行“搜索筛选”，应观察到“列表和选中详情同步更新”，进入 J01-01；取消不产生新的写入。
4. 给定“职位有稳定标识”，执行“保存职位”，应观察到“写入收藏并更新入口”，进入 J02-01；取消不产生新的写入。
5. 给定“职位已选中”，执行“准备申请”，应观察到“创建可编辑本地草稿”，进入 J03-01；取消不产生新的写入。
6. 给定“选定职位及任务范围”，执行“交给Agent”，应观察到“附职位引用进入对话”，进入 A01-01；取消不产生新的写入。
7. 人为制造“来源刷新失败：标旧数据时间，不显示最新”，页面给出可操作恢复入口，不显示成功。
8. 实际结果符合“搜索/收藏有真实数据结果，不虚构投递成功”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
