# J03 申请草稿与预览

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-08 FR-09

## 职责与入口

编辑接收方、附言与附件，提交前核对，不把生成当发送。

- 所属：示例应用/草稿；导航归属：招聘应用 / 申请草稿。
- 进入：职位准备申请、Agent草稿成果。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

对象摘要；附言编辑器；附件区；来源；底部保存/提交

|---|---|
| J03-01 | 草稿编辑 |
| J03-02 | 提交预览 |

## 信息与输入

职位与接收方；附言；附件哈希；账号；目的站点

校验：必填项完整；附件可读；编辑内容或切账号使旧批准失效

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

每次操作记录 source_surface、return_surface、对象版本及选中上下文。以下来源为默认父视图；若从其他子视图触发，以实际来源替代。取消和可恢复失败都留在实际来源，保留输入；涉及已执行的写入则显示回执，不能承诺取消即撤销。

| 操作面 | 来源 | 操作 | 前置条件 | 效果与成功去向 | 取消/失败 |

## 状态与结果

- **J03-S01**：未选附件：可保存草稿，提交显示要求。
- **J03-E01**：结果未知：保留草稿与action引用，不生成第二份提交。
- **J03-R01**：只在站点回执验证后展示已投递。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“字段可序列化”，执行“保存草稿”，应观察到“只保存本地不投递”，进入 J03-01；取消不产生新的写入。
4. 给定“必填与附件检查通过”，执行“预览提交”，应观察到“展示不可变提交摘要”，进入 J03-02；取消不产生新的写入。
5. 给定“账号与目的地明确”，执行“确认投递”，应观察到“进入具体动作确认”，进入 G03-01；取消不产生新的写入。
6. 人为制造“结果未知：保留草稿与action引用，不生成第二份提交”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“只在站点回执验证后展示已投递”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
