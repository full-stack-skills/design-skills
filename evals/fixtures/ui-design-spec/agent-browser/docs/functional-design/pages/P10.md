# P10 任务中心

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-07 FR-12

## 职责与入口

集中管理任务，不与模型对话列表混为一谈。

- 所属：工作空间/任务；导航归属：任务。
- 进入：左侧任务、首页待办。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

全部/运行中/待处理/已结束过滤；任务列表；状态、目标和来源

| 稳定视图 | 职责 |
|---|---|
| P10-01 | 任务列表 |

## 信息与输入

任务目标；来源应用/页面；状态；更新时间；预算摘要；待处理原因

校验：搜索及筛选不改变任务；重复点击不启动第二份任务

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 操作合同

每次操作记录 source_surface、return_surface、对象版本及选中上下文。以下来源为默认父视图；若从其他子视图触发，以实际来源替代。取消和可恢复失败都留在实际来源，保留输入；涉及已执行的写入则显示回执，不能承诺取消即撤销。

## 状态与结果

- **P10-S01**：无任务：展示真实新建入口。
- **P10-E01**：服务断连：旧状态标过期并禁止虚假完成。
- **P10-R01**：任务列表与持久化事件一致。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“任务可访问”，执行“查看任务”，应观察到“打开步骤和证据”，进入 P11-01；取消不产生新的写入。
4. 给定“有目标与选定范围”，执行“新建任务”，应观察到“进入Agent对话”，进入 A01-01；取消不产生新的写入。
5. 给定“任务仍等待批准”，执行“处理确认”，应观察到“查看具体对象和内容”，进入 G03-01；取消不产生新的写入。
6. 人为制造“服务断连：旧状态标过期并禁止虚假完成”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“任务列表与持久化事件一致”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
