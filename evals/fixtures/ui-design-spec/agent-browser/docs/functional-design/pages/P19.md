# P19 版本与恢复

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-12 NFR-05

## 职责与入口

展示真实版本、诊断和恢复路径，不把失败升级隐藏。

- 所属：客户端/数据；导航归属：设置 / 关于与更新。
- 进入：设置版本、启动失败恢复。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

版本与通道；更新详情；下载校验；数据迁移状态；诊断导出

| 稳定视图 | 职责 |
|---|---|
| P19-01 | 版本状态 |

## 信息与输入

当前版本；候选版本；校验；迁移兼容性；日志范围

校验：更新前说明重启任务；仅兼容schema可回滚；支持包脱敏

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P19-S01**：离线：展示当前版本，不冒称最新。
- **P19-E01**：迁移失败：只读恢复且保留备份。
- **P19-R01**：启动成功与数据校验后才算更新成功。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“网络可用”，执行“检查版本”，应观察到“显示可验证更新信息”，进入 P19-01；取消不产生新的写入。
4. 给定“签名有效且任务已安全处理”，执行“安装更新”，应观察到“确认重启影响”，进入 G03-01；取消不产生新的写入。
5. 给定“用户选择脱敏范围”，执行“导出诊断”，应观察到“写本地支持包”，进入 P08-01；取消不产生新的写入。
6. 人为制造“迁移失败：只读恢复且保留备份”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“启动成功与数据校验后才算更新成功”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
