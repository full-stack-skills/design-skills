## 证据与评估

离线评测覆盖观察定位、结构化参数、权限拒绝、陈旧目标、提示注入、结果判断和恢复；使用可控测试站点及固定页面版本。线上记录 task/action/trace 关联、耗时、错误、预算和人工接管原因，敏感内容脱敏。成功率分母包含失败与未知，不能排除困难任务美化指标。

每条验收记录环境、版本、输入、预期、实际、证据文件与结论。静态检查、构建、单测、真实站点运行分别记录。未选定真实目标网站和测试账号时使用受控站点验证，真实网站一栏保持未验证。

## 待决项与处理

- 固定 Servo 的来源桥、登录、沙箱与平台能力：W01 用实测收敛，不改用别的引擎掩盖问题。
- Codex 具体分发版本、协议兼容与认证方式：W01 固定 schema 并核对分发要求。
- 首个真实目标站点和测试账号：真实站点验收前确定；不阻碍本地设计与受控环境工作。
- UI 框架：基于 Servo 特性验证决定；保持已确认视觉结构，不借选型重设计产品。
- 首发平台、签名和性能预算：W07 前确定；不得承诺未经测量的安装包或内存优势。
