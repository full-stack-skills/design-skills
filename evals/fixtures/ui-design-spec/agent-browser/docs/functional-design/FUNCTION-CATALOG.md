# 功能清单

需求语义以 ../product-spec.md 为准。本清单负责功能分解与入口，不创建第二套需求。V1 为目标范围，不代表当前实现。每个页面合同给出可观察验收。

| 功能 ID | 功能 | 业务价值 | 入口 | 范围 | 需求 | 详细合同 |
|---|---|---|---|---|---|---|
| P01 | 应用首页 | 让用户打开应用、继续工作或发起新任务，不混入职位详情。 | 启动、新标签首页、左侧首页 | V1 | FR-01 FR-07 | [合同](pages/P01.md) |
| P02 | 工作台 | 管理一个工作空间内的应用、标签组、任务与成果，区别于个人快捷首页。 | 左侧工作台 | V1 | FR-01 FR-11 | [合同](pages/P02.md) |
| P03 | 应用中心 | 管理内置应用入口与可用状态，首期不建设任意插件市场。 | 工作台应用区、首页管理应用 | V1 | FR-03 FR-04 FR-11 | [合同](pages/P03.md) |
| P04 | 应用详情与运行入口 | 让用户理解应用用途、授权与数据归属，再进入业务页面。 | 应用卡片、应用中心详情 | V1 | FR-03 FR-04 | [合同](pages/P04.md) |
| P05 | 网页浏览 | 正常访问外部网站，保留可信地址和用户接管能力。 | 地址栏、书签、链接、新标签 | V1 | FR-02 FR-05 FR-06 | [合同](pages/P05.md) |
| P06 | 书签管理 | 保存和组织网页入口，不混同浏览历史或知识资料。 | 书签星标、所有书签 | V1 | FR-02 | [合同](pages/P06.md) |
| P07 | 浏览历史 | 按时间检索和重新打开浏览记录，并明确清除范围。 | 左侧历史 | V1 | FR-02 | [合同](pages/P07.md) |
| P08 | 下载中心 | 跟踪文件下载、结果与失败，安全地定位本地文件。 | 左侧下载、下载图标 | V1 | FR-02 FR-12 | [合同](pages/P08.md) |
| P09 | 网站账号与会话 | 隔离不同站点账号，管理登录状态和数据清除。 | 设置网站账号、地址栏profile菜单 | V1 | FR-05 FR-08 | [合同](pages/P09.md) |
| P10 | 任务中心 | 集中管理任务，不与模型对话列表混为一谈。 | 左侧任务、首页待办 | V1 | FR-07 FR-12 | [合同](pages/P10.md) |
| P11 | 任务详情 | 观察执行过程、接管和恢复，展示结果证据而非只有聊天。 | 任务行、Agent“查看任务” | V1 | FR-07 FR-08 FR-12 | [合同](pages/P11.md) |
| P12 | 成果与证据 | 让用户查看、核对、导出或保存真实任务输出。 | 任务结果、工作台成果 | V1 | FR-07 FR-10 | [合同](pages/P12.md) |
| P13 | 知识库 | 管理用户保存的文件、网页摘录和结构化成果。 | 左侧知识库 | V1 | FR-10 | [合同](pages/P13.md) |
| P14 | 资料详情 | 阅读资料、追溯来源和选段交给Agent。 | 知识库列表、成果保存完成 | V1 | FR-10 | [合同](pages/P14.md) |
| P15 | 记忆管理 | 让用户查看、纠正和删除可复用偏好与经验。 | Agent记忆页签、设置数据管理 | V1 | FR-10 | [合同](pages/P15.md) |
| P16 | 设置中心 | 集中组织浏览器、智能体、权限、数据与更新设置。 | 左侧设置、菜单设置 | V1 | FR-11 NFR-05 | [合同](pages/P16.md) |
| P17 | 智能体连接与模型 | 配置Codex载体、可用模型和认证，明确本地载体不等于本地模型。 | 设置智能体、模型不可用提示 | V1 | FR-07 NFR-01 | [合同](pages/P17.md) |
| P18 | 工具与能力管理 | 展示应用和智能体可用工具及其授权范围。 | 设置、工具拒绝提示 | V1 | FR-04 FR-08 | [合同](pages/P18.md) |
| P19 | 版本与恢复 | 展示真实版本、诊断和恢复路径，不把失败升级隐藏。 | 设置版本、启动失败恢复 | V1 | FR-12 NFR-05 | [合同](pages/P19.md) |
| P20 | 产品配置 | 用一套引擎配置多个产品，不复制浏览器业务代码。 | 有管理权限的设置入口 | V1.1 | FR-11 | [合同](pages/P20.md) |
| J01 | 职位搜索与详情 | 完整还原参考图的职位业务区，作为一方应用示例，不绑定浏览器核心。 | 首页招聘应用卡、固定标签 | V1 | FR-09 | [合同](pages/J01.md) |
| J02 | 已保存职位与对比 | 对比用户选中的职位并保留来源，不展示无依据匹配分数。 | 职位收藏、应用已保存 | V1 | FR-09 FR-10 | [合同](pages/J02.md) |
| J03 | 申请草稿与预览 | 编辑接收方、附言与附件，提交前核对，不把生成当发送。 | 职位准备申请、Agent草稿成果 | V1 | FR-08 FR-09 | [合同](pages/J03.md) |
| A01 | Agent工作台 | 以Codex为内嵌载体呈现对话、页面理解、任务和记忆，和网页并存。 | 顶部Agent按钮、业务交给Agent | V1 | FR-06 FR-07 FR-08 FR-10 | [合同](pages/A01.md) |
