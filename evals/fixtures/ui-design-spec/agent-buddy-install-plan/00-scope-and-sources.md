# 范围、来源与决定

这是从 Agent Buddy 已有成果规范化得到的**单功能教学切片**，演示固定合同的完整交付形态。ready 仅表示这一教学切片的规格与引用已检查，不表示原项目评审完成、功能实现或运行通过。

## 范围

- 产品：Agent Buddy；用户：为本机 Runtime 安装 Agent 的操作者。
- 对象：InstallPlan、来源版本、目标路径、文件摘要与备份引用。
- 包含：F07 安装计划预览及计划过期时回到预览。
- 不包含：来源选择、审批执行、写盘、生效与回滚；这些保持原 F06/F08/F09，不在本切片中宣称覆盖。
- 正式需求与实施状态仍位于原项目 OpenSpec；本目录仅为可移植只读样例。

## 来源

SRC1：source-snapshots/product-excerpts.md，包含原 F07 和 B06 文档摘录，证据等级 design。SRC2：source-snapshots/tasks.md，包含正式任务 2.2、2.6 的只读摘录，证据等级 spec。完整来源路径及内容散列见 source-snapshots/provenance.json。工作区快照不能用仓库 HEAD 代替。

## 本样例的设计细化

原成果提供字段方向及返回规则。本样例补充页头/主体布局、键盘返回、禁用条件和验证步骤，作为教学设计，不冒充原文或已确认产品要求。JSON 与 Markdown 描述同一个有限范围。

## 冲突

全局“终端/运行环境”的历史冲突不在本切片中裁定；使用 Runtime 对象名称。读取完整项目时必须回到现行确认记录解决导航口径，不能用本样例覆盖它。
