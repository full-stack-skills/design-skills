## B06 原文

 · 运行环境域内流程 / P0

**入口与问题**：B08/B05/B10 安装；“我将把哪个版本写入哪里，是否安全？”

**结构**：固定步骤条、可返回草稿、来源与目标摘要、文件差异/权限/备份/冲突、准确计划摘要。向导结束不等于安装成功。

| Surface | 触发与必需信息 | 去向/结果 |
| --- | --- | --- |
| B06-01 选择来源与版本 | Git/PaaS/本地来源、Bundle 摘要和可信状态 | 下一步 B06-02 |
| B06-02 选择目标 | Runtime、全局/项目范围、路径与权限 | 下一步预览；不支持目标阻断 |
| B06-03 冻结计划 | 文件清单、原文件摘要、差异、备份引用和风险 | 审批后 B07；返回修改需重算 |
| B06-A01 精确批准 | 显示计划 ID、摘要、目标、参数与到期 | BG02；通过才提交 |
| B06-S01 计划生成中 | 后台计算、旧草稿可见 | 完成后可审阅 |
| B06-E01 计划过期 | 文件/目标/来源版本变化 | 回 B06-03 重新预览与批准 |
| B06-E02 权限/冲突阻断 | 用户文件冲突或目标不可写 | 解决或取消，不自动覆盖 |
