# 功能清单

## F07 冻结计划与差异预览

- 目标：操作者清楚知道将写入哪个来源版本、哪些目标与文件。
- 前提：来源与目标已选择；只读预览权限有效。
- 输入：来源版本、目标路径、范围、原文件摘要。
- 输出：带计划 ID 的差异、风险、备份引用与权限摘要。
- 权限：只读预览不能获得写盘权限。
- 异常：目标/来源/文件摘要变化使计划过期；原计划失效并重新预览。
- 优先级：安装主链 P0；成熟度：目标设计，未运行验证。
- 入口：B06 下的 B06-03；异常：B06-E01；旅程 J-F07。
- 验收：变更目标文件后旧计划不可继续，重新预览必须绑定新摘要；无副作用预览不得写安装文件。
- 来源：SRC1，任务映射 SRC2。
