# P08 下载中心

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-02 FR-12

## 职责与入口

跟踪文件下载、结果与失败，安全地定位本地文件。

- 所属：工作空间/文件；导航归属：下载。
- 进入：左侧下载、下载图标。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

进行中/已完成/失败分区；进度与速度；文件操作

| 稳定视图 | 职责 |
|---|---|
| P08-01 | 下载列表 |

## 信息与输入

文件名；来源域；目标目录；字节进度；状态；校验结果

校验：文件名规范化；覆盖要确认；打开可执行文件不默认触发

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 操作合同

每次操作记录 source_surface、return_surface、对象版本及选中上下文。以下来源为默认父视图；若从其他子视图触发，以实际来源替代。取消和可恢复失败都留在实际来源，保留输入；涉及已执行的写入则显示回执，不能承诺取消即撤销。

| 操作面 | 来源 | 操作 | 前置条件 | 效果与成功去向 | 取消/失败 |
|---|---|---|---|---|---|
| P08-A01 | P08-01 | 打开文件位置 | 文件存在 | 请求本机定位并显示结果 → P08-01 | 取消回实际来源；校验失败原位指出原因；结果未知进入核对 |
| P08-A02 | P08-01 | 取消下载 | 任务仍在传输 | 停止传输并标取消 → P08-01 | 取消回实际来源；校验失败原位指出原因；结果未知进入核对 |
| P08-A03 | P08-01 | 重新下载 | 原来源可访问 | 重新校验账号和目的路径 → P08-01 | 取消回实际来源；校验失败原位指出原因；结果未知进入核对 |

## 状态与结果

- **P08-S01**：无下载；传输暂停时保持真实进度。
- **P08-E01**：磁盘不足/文件缺失/鉴权失效：分别提供改路径、定位或登录。
- **P08-R01**：完成来自文件落盘与校验，不仅 HTTP 200。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“文件存在”，执行“打开文件位置”，应观察到“请求本机定位并显示结果”，进入 P08-01；取消不产生新的写入。
4. 给定“任务仍在传输”，执行“取消下载”，应观察到“停止传输并标取消”，进入 P08-01；取消不产生新的写入。
5. 给定“原来源可访问”，执行“重新下载”，应观察到“重新校验账号和目的路径”，进入 P08-01；取消不产生新的写入。
6. 人为制造“磁盘不足/文件缺失/鉴权失效：分别提供改路径、定位或登录”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“完成来自文件落盘与校验，不仅 HTTP 200”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
