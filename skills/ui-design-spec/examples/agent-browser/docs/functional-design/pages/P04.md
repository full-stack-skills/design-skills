# P04 应用详情与运行入口

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-03 FR-04

## 职责与入口

让用户理解应用用途、授权与数据归属，再进入业务页面。

- 所属：应用；导航归属：工作台 / 应用详情。
- 进入：应用卡片、应用中心详情。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 信息与输入

用途；版本；权限；本地数据位置说明；最近运行；更新状态

校验：编辑权限按能力与路径范围；应用卸载和数据删除分开

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P04-S01**：应用未启用：主按钮显示启用而非打开。
- **P04-E01**：本地资源缺失：禁止运行，提供修复入口。
- **P04-R01**：应用标签获得确定 app_id 与受限能力范围。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“应用已启用”，执行“打开示例应用”，应观察到“打开招聘内置页面”，进入 J01-01；取消不产生新的写入。
4. 给定“当前用户有管理权”，执行“调整授权”，应观察到“进入能力范围确认”，进入 G05-01；取消不产生新的写入。
5. 给定“存在版本记录”，执行“查看版本”，应观察到“进入更新与恢复”，进入 P19-01；取消不产生新的写入。
6. 人为制造“本地资源缺失：禁止运行，提供修复入口”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“应用标签获得确定 app_id 与受限能力范围”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
