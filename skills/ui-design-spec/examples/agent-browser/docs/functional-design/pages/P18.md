# P18 工具与能力管理

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-04 FR-08

## 职责与入口

展示应用和智能体可用工具及其授权范围。

- 所属：工作空间/授权；导航归属：设置 / 工具与权限。
- 进入：设置、工具拒绝提示。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 信息与输入

工具名称；提供者；输入范围；副作用；最近使用；来源

校验：首期不提供任意本地代码插件；禁用影响后续调用不撤回既有副作用

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P18-S01**：无可用工具：提示配置一方应用。
- **P18-E01**：工具契约不兼容：隔离而非默认放行。
- **P18-R01**：授权显示有效版本与范围。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“用户可授权且工具可信”，执行“调整范围”，应观察到“选择域名/文件/profile范围”，进入 G05-01；取消不产生新的写入。
4. 给定“有历史记录”，执行“查看调用”，应观察到“进入任务执行过程”，进入 P11-01；取消不产生新的写入。
5. 给定“显示相关运行任务”，执行“停用能力”，应观察到“确认后撤销后续调用”，进入 G03-01；取消不产生新的写入。
6. 人为制造“工具契约不兼容：隔离而非默认放行”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“授权显示有效版本与范围”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
