# P15 记忆管理

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-10

## 职责与入口

让用户查看、纠正和删除可复用偏好与经验。

- 所属：工作空间/用户偏好；导航归属：Agent / 记忆。
- 进入：Agent记忆页签、设置数据管理。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

偏好/站点经验列表；来源和有效期；编辑与忘记

| 稳定视图 | 职责 |
|---|---|
| P15-01 | 记忆列表 |

## 信息与输入

内容；类型；来源任务；适用域；建立时间；失效时间

校验：不保存Cookie密码；编辑后增加revision；经验不是权限

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P15-S01**：无记忆：说明何时形成、由谁保存。
- **P15-E01**：来源失效：标过期，不自动作为执行依据。
- **P15-R01**：删除后不再检索或进入新上下文。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“来源可见且可编辑”，执行“编辑记忆”，应观察到“保存新内容和版本”，进入 P15-01；取消不产生新的写入。
4. 给定“显示检索与缓存范围”，执行“忘记记忆”，应观察到“确认删除”，进入 G03-01；取消不产生新的写入。
5. 给定“原任务仍可访问”，执行“查看来源”，应观察到“回看任务证据”，进入 P11-01；取消不产生新的写入。
6. 人为制造“来源失效：标过期，不自动作为执行依据”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“删除后不再检索或进入新上下文”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
