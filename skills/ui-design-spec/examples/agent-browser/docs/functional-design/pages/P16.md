# P16 设置中心

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-11 NFR-05

## 职责与入口

集中组织浏览器、智能体、权限、数据与更新设置。

- 所属：用户/客户端；导航归属：设置。
- 进入：左侧设置、菜单设置。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 信息与输入

外观；启动页；缩放；语言；下载目录；快捷键；默认profile

校验：更改影响当前还是新标签须明确；恢复默认不删数据

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P16-S01**：首次配置：给安全默认值。
- **P16-E01**：保存失败：保留原值和未保存提示。
- **P16-R01**：仅成功持久化的值标已保存。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“用户主动选择”，执行“设置模型账号”，应观察到“打开智能体配置”，进入 P17-01；取消不产生新的写入。
4. 给定“用户主动选择”，执行“管理网站账号”，应观察到“进入profile列表”，进入 P09-01；取消不产生新的写入。
5. 给定“客户端可管理”，执行“查看更新”，应观察到“进入版本恢复”，进入 P19-01；取消不产生新的写入。
6. 给定“用户主动选择”，执行“管理能力”，应观察到“查看已授予范围”，进入 P18-01；取消不产生新的写入。
7. 人为制造“保存失败：保留原值和未保存提示”，页面给出可操作恢复入口，不显示成功。
8. 实际结果符合“仅成功持久化的值标已保存”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
