# P02 工作台

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-01 FR-11

## 职责与入口

管理一个工作空间内的应用、标签组、任务与成果，区别于个人快捷首页。

- 所属：工作空间；导航归属：工作台。
- 进入：左侧工作台。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

## 界面结构

头部空间名与摘要；主体“进行中/已保存”切换；应用和标签组列表；成果区域

| 稳定视图 | 职责 |
|---|---|
| P02-01 | 进行中 |
| P02-02 | 已保存 |

## 信息与输入

空间名称；标签组名称/标签数；任务状态；成果类型/来源

校验：名称必填，重名时提示；切空间不携带旧账号或附件授权

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 操作合同

每次操作记录 source_surface、return_surface、对象版本及选中上下文。以下来源为默认父视图；若从其他子视图触发，以实际来源替代。取消和可恢复失败都留在实际来源，保留输入；涉及已执行的写入则显示回执，不能承诺取消即撤销。

| 操作面 | 来源 | 操作 | 前置条件 | 效果与成功去向 | 取消/失败 |
|---|---|---|---|---|---|
| P02-A01 | P02-01 | 打开应用中心 | 当前空间可编辑 | 查看可用应用 → P03-01 | 取消回实际来源；校验失败原位指出原因；结果未知进入核对 |
| P02-A02 | P02-01 | 查看全部任务 | 空间已选择 | 按空间过滤任务 → P10-01 | 取消回实际来源；校验失败原位指出原因；结果未知进入核对 |
| P02-A03 | P02-01 | 查看成果 | 有可访问结果 | 打开结果记录 → P12-01 | 取消回实际来源；校验失败原位指出原因；结果未知进入核对 |

## 状态与结果

- **P02-S01**：空空间：引导添加应用或打开网页。
- **P02-E01**：空间不可访问：退出上下文并要求选择其他空间。
- **P02-R01**：空间聚合视图更新，不改写任务事实。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“当前空间可编辑”，执行“打开应用中心”，应观察到“查看可用应用”，进入 P03-01；取消不产生新的写入。
4. 给定“空间已选择”，执行“查看全部任务”，应观察到“按空间过滤任务”，进入 P10-01；取消不产生新的写入。
5. 给定“有可访问结果”，执行“查看成果”，应观察到“打开结果记录”，进入 P12-01；取消不产生新的写入。
6. 人为制造“空间不可访问：退出上下文并要求选择其他空间”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“空间聚合视图更新，不改写任务事实”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
