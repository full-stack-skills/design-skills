# P06 书签管理

设计 Draft · 实现未验收 · 范围 V1 · 对应 FR-02

## 职责与入口

保存和组织网页入口，不混同浏览历史或知识资料。

- 所属：工作空间/Profile；导航归属：书签栏 / 所有书签。
- 进入：书签星标、所有书签。
- 返回：保留来源标签、工作空间、选中对象、筛选和滚动；深链无来源时返回所属导航首页。

文件夹树；搜索/批量工具栏；书签列表；编辑抽屉

## 信息与输入

标题；URL；文件夹；创建时间；profile 提示

校验：URL协议校验；删除文件夹说明包含项目；重名可允许但相同URL提示重复

对象选择必须使用稳定 ID，不以列表行号定位。页面切换不会把其他工作空间或账号的对象带入当前操作。

## 状态与结果

- **P06-S01**：无书签：引导地址栏星标。
- **P06-E01**：写入失败：保持旧数据并允许重试。
- **P06-R01**：保存后列表与书签栏一致。
- 初次加载显示页面骨架和真实进度；已有数据刷新保留内容并标刷新状态。
- 无数据解释原因并给出首个有效入口；筛选无结果保留筛选，允许清除。
- 网络失败保留本地内容；仅联网操作不可用并说明恢复方式。
- 权限不足给出所需范围和设置入口；授权撤销后立即停止新的受限操作。
- 并发修改提示对象已变化，重新加载并核对；禁止用旧版本静默覆盖。

## 验收场景

1. 从指定入口进入，能明确识别当前工作空间、对象和主操作；返回恢复来源上下文。
2. 每个稳定视图均有明确选中态、内容区和独立深链；刷新不会串对象。
3. 给定“目标可解析”，执行“打开书签”，应观察到“在当前或新标签访问”，进入 P05-01；取消不产生新的写入。
4. 给定“选中单条”，执行“编辑书签”，应观察到“保存标题地址和目录”，进入 P06-01；取消不产生新的写入。
5. 给定“选择非空”，执行“删除选中”，应观察到“列出范围并确认”，进入 G03-01；取消不产生新的写入。
6. 人为制造“写入失败：保持旧数据并允许重试”，页面给出可操作恢复入口，不显示成功。
7. 实际结果符合“保存后列表与书签栏一致”，并可从来源再次找到；不能以按钮点击或模型回答替代验证。
