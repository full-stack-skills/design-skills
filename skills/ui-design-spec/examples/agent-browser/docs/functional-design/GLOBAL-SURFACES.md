# 全局交互合同

全局面不重建第二套导航。实际返回位置来自 return_surface；下表 target 仅是没有来源时的回退。确认面必须覆盖具体内容，不能只显示“是否继续”。

## SH01-01 浏览器外壳

- 入口：标签/地址/书签/侧栏。
- 呈现：宿主可信窗口；结构：标签标题、真实地址、导航、书签、全局侧栏；中央内容容器与Agent侧栏分开。
- 信息：活动标签、页面来源、安全状态、profile、窗口缩放。
- 确认效果：打开、关闭、切换标签与输入URL；地址栏不得显示伪造站点。
- 异常与取消：关闭有未保存输入或运行依赖的标签时确认；正常切换保留各页状态。
- 返回：优先实际来源；无来源回退 P05-01。
- 验收：入口可达、焦点受控、取消恢复来源；确认结果可观察并持久化。

## G01-01 工作空间切换

- 入口：顶部工作空间入口。
- 呈现：Popover；结构：空间列表、最近空间、当前勾选与运行任务提示。
- 信息：workspace_id、名称、未决任务数。
- 确认效果：切换时清除旧页面上下文授权，旧任务留在原空间。
- 异常与取消：存在未决提交时先提示核对或保持原空间。
- 返回：优先实际来源；无来源回退 P02-01。
- 验收：入口可达、焦点受控、取消恢复来源；确认结果可观察并持久化。

## G02-01 统一搜索与地址建议

- 入口：地址栏聚焦/全局搜索。
- 呈现：Popover；结构：输入框、地址/书签/历史/应用分组建议。
- 信息：查询、类型、来源、目标。
- 确认效果：输入URL导航；输入应用名打开应用；自然语言需显式交给Agent。
- 异常与取消：空输入显示最近；没有结果允许搜索，禁止自动执行业务任务。
- 返回：优先实际来源；无来源回退 P05-01。
- 验收：入口可达、焦点受控、取消恢复来源；确认结果可观察并持久化。

## G03-01 具体动作确认

- 入口：有外部写入/删除/更新的操作。
- 呈现：Overlay；结构：对象与影响、账号/目的地、内容/附件摘要、过期时间；取消和唯一确认按钮。
- 信息：prepared_action_id、digest、return_surface、workspace、profile。
- 确认效果：批准绑定摘要；执行时再次验证，不能以通用确认替代具体内容。
- 异常与取消：内容变化/账号变化/过期时阻断并回到来源重新准备；取消不执行。
- 返回：优先实际来源；无来源回退 P11-01。
- 验收：入口可达、焦点受控、取消恢复来源；确认结果可观察并持久化。

## G04-01 登录与人工接管

- 入口：网站需认证或模型认证入口。
- 呈现：Takeover；结构：原因、目标站点或认证服务、可见页面、完成接管按钮。
- 信息：站点URL、profile或认证提供者、关联任务、返回上下文。
- 确认效果：用户完成登录后重新观察；登录网页与Codex认证是不同会话。
- 异常与取消：用户取消回到来源保持任务待接管；不能只凭按钮点击认定已登录。
- 返回：优先实际来源；无来源回退 P05-01。
- 验收：入口可达、焦点受控、取消恢复来源；确认结果可观察并持久化。

## G05-01 上下文与能力授权

- 入口：添加应用/调整工具/选择上下文。
- 呈现：Overlay；结构：申请者、目的、页面/文件/域名范围、只读或写入、有效期。
- 信息：capability、scope、principal、expiry、return_surface。
- 确认效果：选择最小范围并确认；上下文引用与执行权限分开。
- 异常与取消：权限不足或范围非法拒绝；取消维持原授权。
- 返回：优先实际来源；无来源回退 A01-01。
- 验收：入口可达、焦点受控、取消恢复来源；确认结果可观察并持久化。

## G06-01 通知与待处理

- 入口：顶部通知图标。
- 呈现：Drawer；结构：按任务/下载/更新分类；时间、状态、处理入口。
- 信息：notification_id、source_id、timestamp、status。
- 确认效果：点击通知定位对应任务或设置，已读不等于处理。
- 异常与取消：来源删除时标不可访问而非跳到无关对象。
- 返回：优先实际来源；无来源回退 P10-01。
- 验收：入口可达、焦点受控、取消恢复来源；确认结果可观察并持久化。

## G07-01 退出与恢复

- 入口：关闭窗口/启动检测到未决任务。
- 呈现：Overlay；结构：运行任务、未保存草稿、未知提交；退出/返回或核对。
- 信息：task_refs、draft_refs、recovery_state。
- 确认效果：退出不默认撤回副作用；恢复不自动重放提交。
- 异常与取消：持久化失败时禁止声称已安全保存。
- 返回：优先实际来源；无来源回退 P11-01。
- 验收：入口可达、焦点受控、取消恢复来源；确认结果可观察并持久化。

## SH01 外壳操作明细

这些为 SH01-01 内的常驻控件行为，不额外编造页面。实现测试逐项覆盖。

| 控件 | 用户操作 | 界面与数据变化 | 边界与返回 |
|---|---|---|---|
| 新标签 | 点击加号/快捷键 | 打开应用首页，地址栏可立即输入 | 不继承其他任务的写入授权 |
| 切换标签 | 点击标签或键盘选择 | 主内容、真实地址、加载状态同步 | Agent 原任务目标不自动变更 |
| 关闭标签 | 关闭按钮/快捷键 | 检查未保存内容和依赖任务后关闭 | 有未决动作先说明；最近关闭可恢复页面，不重放操作 |
| 地址栏 | 输入地址并确认 | 校验协议，当前标签导航，显示真实最终 URL | 非法协议阻断；自然语言需明确交给 Agent |
| 前进/后退 | 点击导航按钮 | 使用该标签导航历史 | 无历史时禁用，不撤销业务写入 |
| 刷新/停止 | 点击状态按钮 | 导航中为停止，否则刷新 | 表单重发需提示，不能自动重复提交 |
| 书签 | 点击收藏 | 保存或编辑标题与 URL，当前页状态同步 | 同一地址避免无提示重复，管理入口 P06 |
| 下载 | 点击下载入口 | 定位 P08 真实下载记录 | 进度来自实际传输与落盘，不靠计时模拟 |
| 工作空间 | 打开 G01 | 列出范围、活跃任务并切换 | 不把旧账号会话内容带到新工作空间 |
| Agent 开关 | 打开/收起右栏 | 恢复关联会话和输入草稿 | 收起不暂停任务；暂停使用明确控件 |
| 页面失败 | 重试/返回 | 原位说明 TLS/网络/崩溃等原因 | 不绕过证书错误伪造安全状态 |

## 全局确认的执行语义

打开 G03 只表示准备审查，不是已经执行。其“确认”按钮提交绑定摘要的批准，服务层复核后才执行；执行期间显示状态，成功回到具体业务结果，失败保留来源和原因。外部结果未知转 P11 核对。用户关闭确认面不触发执行；确认已送达后关闭仅改变展示，不能声称撤销。
