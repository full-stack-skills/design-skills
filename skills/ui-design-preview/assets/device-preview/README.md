# AgentScope Phone / Pad 交互设计原型

以本地HTTP服务打开 `review.html`，可并排操作390×884与768×1024两端。`index.html`为独立响应式原型。无构建依赖；无需连接模型、数据库或Agent Buddy。

从当前原型目录运行（完整目录可复制到任意位置）：

```sh
python3 serve.py --port 8872
```

打开终端输出的本地地址：`http://127.0.0.1:8872/review.html?section=models`。原有仓库根目录服务及评审地址仍可使用。

## 范围

主界面、抽屉、对话、工作、能力目录/详情、示例知识文档、任务/定时创建、个人入口、11类移动设置。Pad采用导航轨与目录主从布局；手机采用底栏、抽屉与设置逐级返回。两端不暴露桌面控制入口。

配置与目录夹具保存在当前浏览器，模型Key不保存。定时任务只在页面内存中，刷新后不保留。文件选择只记录名称与大小，不读取或上传文件。语音、模型执行、系统授权、实际安装、调度、同步与完整文件管理均未接入。

Desktop按2026-09-30最新决定复用Agent Buddy；本目录残留的Desktop截图/宽屏布局仅为前次探索，不继续发展为独立Desktop设计。

## 验证

`verify_ui.py`需要已安装的Python Playwright与Chrome，浏览器位置可通过`CHROME_PATH`覆盖，默认自动启动并关闭临时本地服务，服务地址可通过`DEMO_URL`覆盖。不自动安装依赖。检查的是可观察的UI流程，不是模型/原生运行能力。

```sh
python3 verify_ui.py
python3 verify_review.py
```

`review/verification.json`记录Phone/Pad结果；截图为同次浏览器运行产物。旧Q图Registry和本目录互相独立，不能将截图数量计为Q合同已完成。

## 模型设置与能力导入修订

使用 `review.html?section=models` 直接对照 Phone 供应商详情与 Pad 双栏模型工作区。Pad 模型页临时展开全宽，返回后恢复设置分类侧栏；Phone 从供应商列表进入详情。保留可搜索的添加供应商目录，每个供应商允许多份独立配置。

模型列表同时提供“添加模型”和“获取模型”。手填 ID 支持编辑、去重与删除；获取面板支持搜索、多选、跳过已有项、空结果及失败重试。“演示响应”选择器只切换确定性夹具，不请求真实服务。切换供应商或返回时，未保存配置可取消、放弃或保存后继续。所有配置均未验证，开关只表达使用偏好。

技能、子智能体、插件管理均提供链接/ZIP 导入。系统选择器可选真实文件，但本原型只校验扩展名、大小并展示来源元数据；不读取包内容。预览可改名，同名阻止覆盖，确认后保存默认不启用的待验证草稿。真实下载、解压、清单校验及安装仍须接入运行时。

OpenAI示例地址取自[官方API说明](https://developers.openai.com/api/reference/overview)，此处仅用于展示可编辑默认值。未核验预置保持空值，团队网关使用 example.com。所有 demo-* 模型 ID 都是演示数据；不编造模型上下文或视觉能力。

回归覆盖指定视口的导航、浅深色、密钥隔离、手填/获取模型合并、导入三种能力的两条路径与错误状态。`review/verification.json` 记录结果。三张已认可截图另与 `review/alignment-baseline/baseline.json` 逐文件核对。

## 同步评审操作

评审页默认同步两端页面与主题。顶部页面选择、上一页/下一页、任一端的快捷选择，以及界面内导航、弹窗开关与选项卡都能联动；关闭“同步两端”后可分别操作，重新开启时采用最近操作端。评审URL保存页面、主题与同步状态，刷新可恢复；加载较慢的设备按最终选择显示。同步仅控制预览场景，不复制输入、保存、导入或其他业务动作。

逻辑视口固定为Phone 390×884、Pad 768×1024，外层缩放只为并排展示。完整代码可整体复制运行，品牌SVG位于本目录assets内；`serve.py`仅监听127.0.0.1，`verify_review.py`检验评审联动与资源闭合。

内部联动由 `preview-bridge.js` 将已登记的导航操作转换为只含页面身份、主题和选项卡的状态，评审器再交给另一端应用。接入新页面需补充白名单与实际点击断言；不重放任意点击。可以打开导入插件，在 Pad 点击“压缩文件”，直接观察 Phone 同步切换。URL恢复页面和主题，内部临时弹窗子状态不持久化。

## 中等按钮尺寸

`buttons.css`统一常规操作按钮为40px高、14px字、20px行高、14px横向内边距、10px圆角；图标按钮为40×40。Phone/Pad与浅深主题共用尺寸。页面允许工具栏换行，不再缩小按钮；导航列表、可点击内容卡片、开关与遮罩保留结构尺寸。已确认截图保留在alignment-baseline，新的按钮截图单独生成。

运行 `python3 verify_buttons.py` 检查28个场景、两端两主题及附加弹窗，报告按钮高度、图标宽度、文字裁切、工具栏溢出与未分类按钮。结果在 `review/button-verification.json`，对照截图为 `review/buttons-medium-light.png` 和 `review/buttons-medium-dark.png`。
